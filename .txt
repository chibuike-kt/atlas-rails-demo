STEP 0 — Reset to a clean database (important)

From repo root:

rm -f storage/demo.sqlite
./bin/migrate
./bin/seed
composer dump-autoload -o

STEP 1 — Start all processes

Open three terminals.

Terminal 1 — API
php -S 127.0.0.1:8000 -t public

Terminal 2 — Worker
./bin/worker

Terminal 3 — Scheduler loop
while true; do ./bin/scheduler; sleep 1; done


Do not proceed until all three are running.

STEP 3 — Run the demo (SEND IN THIS ORDER)
1) Health Check

GET

{{baseUrl}}/health


Must return { "ok": true }.

2) Create User

POST

{{baseUrl}}/users


Headers:

Content-Type: application/json
Idempotency-Key: create-user-001
X-Correlation-Id: corr-user-001


Body:

{
  "email": "demo@example.com"
}


Tests tab:

const r = pm.response.json();
pm.environment.set("userId", r.user.id);

3) Start Bank Link

POST

{{baseUrl}}/bank_links/start


Headers:

Content-Type: application/json
Idempotency-Key: link-start-001
X-Correlation-Id: corr-link-001


Body:

{
  "user_id": "{{userId}}"
}


Tests:

const r = pm.response.json();
pm.environment.set("bankRef", r.external_ref);

4) Complete Bank Link

POST

{{baseUrl}}/bank_links/complete

5) Fund Fiat Balance (ASYNC → worker settles)

POST

{{baseUrl}}/fiat/fund


Headers:

Content-Type: application/json
Idempotency-Key: fund-001
X-Correlation-Id: corr-fund-001


Body:

{
  "user_id": "{{userId}}",
  "amount_minor": 500000,
  "bank_external_ref": "{{bankRef}}"
}

👀 Observe:

GET

{{baseUrl}}/jobs?correlation_id=corr-fund-001


GET

{{baseUrl}}/audit?correlation_id=corr-fund-001


GET

{{baseUrl}}/balances?user_id={{userId}}


Balance should now show NGN credited.
